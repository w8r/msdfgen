<task type="auto">
  <name>Task 5: Implement cursor-centered zoom</name>
  <files>demo/webgpu-demo.ts</files>
  <action>
Add wheel event listener to canvas in webgpu-demo.ts:

Per RESEARCH.md "Pattern 2: Cursor-Centered Zoom":
1. Get mouse position in canvas space: (mx, my) relative to canvas.getBoundingClientRect()
2. Transform mouse to world space BEFORE zoom: worldBefore = { x: (mx - viewport.panX) / viewport.zoom, y: (my - viewport.panY) / viewport.zoom }
3. Update zoom: zoomDelta = event.deltaY > 0 ? 0.9 : 1.1, newZoom = viewport.setZoom(viewport.zoom * zoomDelta)
4. Transform mouse to world space AFTER zoom: worldAfter = { x: (mx - viewport.panX) / newZoom, y: (my - viewport.panY) / newZoom }
5. Adjust pan: viewport.setPan(viewport.panX + (worldBefore.x - worldAfter.x) * newZoom, viewport.panY + (worldBefore.y - worldAfter.y) * newZoom)

Smoothing (per CONTEXT.md "200-300ms animations"): Use smooth animation for zoom/pan transitions:
- Store targetZoom and targetPan, interpolate over 250ms with easing function (easeOutCubic)
- Per RESEARCH.md "Smooth Zoom/Pan Animation with Lerp" code example
- Update viewport.zoom/panX/panY gradually in render loop until target reached

Prevent default wheel behavior: event.preventDefault() to avoid page scroll.
  </action>
