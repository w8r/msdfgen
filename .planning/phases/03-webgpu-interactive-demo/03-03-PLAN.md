<task type="auto">
  <name>Task 1: Extend MSDFRenderer for split-screen rendering</name>
  <files>demo/renderer/MSDFRenderer.ts</files>
  <action>
Update MSDFRenderer.render() method signature and implementation:

Old signature: render(viewMatrix: Float32Array): void
New signature: render(viewMatrix: Float32Array, splitScreen: boolean = false, modeLeft?: number, modeRight?: number): void

If splitScreen=false: Use existing single-viewport rendering (current behavior)

If splitScreen=true:
- Per RESEARCH.md "Pattern 4: Split-Screen Rendering"
- Compute halfWidth = Math.floor(canvas.width / 2)
- Left half:
  - renderPass.setViewport(0, 0, halfWidth, canvas.height, 0, 1)
  - renderPass.setScissorRect(0, 0, halfWidth, canvas.height)
  - Update uniform buffer mode field to modeLeft (use writeBuffer at offset)
  - renderPass.draw(6, instanceCount)
- Right half:
  - renderPass.setViewport(halfWidth, 0, canvas.width - halfWidth, canvas.height, 0, 1)
  - renderPass.setScissorRect(halfWidth, 0, canvas.width - halfWidth, canvas.height)
  - Update uniform buffer mode field to modeRight
  - renderPass.draw(6, instanceCount)

Optimization: Reuse same render pass, no need to recreate. Only update uniforms between draw calls.

Add visual divider (optional enhancement): Draw vertical line at split point in a second render pass (or CSS overlay).
  </action>
